# Dhairya Sansi — Night Line
Personal portfolio for Dhairya Sansi, an ECE undergraduate at Manipal University Jaipur. The static site is published at https://dhairya11111.github.io/ by GitHub Pages from main.

Serve the repository with `python3 -m http.server 8000`. The experience timeline, project links, résumé and contact details are ordinary HTML. JavaScript adds the workbench selector, layered skyline, scroll choreography and optional synthesized station chimes. The pointer effect is restricted to fine pointers, and visitors can pause scene motion or use their system’s reduced-motion setting.

CSS and scripts are linked with content revision queries. The current layout uses night-line.css and night-line.js. The earlier styles.css and script.js are retained for visitors with a cached earlier page. Font licenses are included in assets/fonts.
