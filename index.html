Computer vision Featured

Cracks and Debris Detection Model

Built an end-to-end real-time industrial inspection system for detecting surface defects in metal pistons. The setup uses high-grade external cameras to capture live video while the piston rotates automatically for 2-3 seconds, giving the model full surface coverage.

A custom-trained YOLO detection and segmentation model analyzes each frame to find defects such as cracks, discoloration, chips, bruises, and water stains, then classifies the piston as "Approved" or "Not OK" for a quality-control workflow.

  • Python
  • OpenCV
  • Ultralytics YOLO
  • Real-time video
  • Flask/FastAPI
  • High-grade cameras
Robotics Featured

Heavy-Duty Line Following Robot

Made a heavy-duty line following robot associated with Abilities India Pistons and Rings Limited. The robot uses an Arduino Mega and can carry payloads up to 15 kg, making it suitable for heavier movement tasks.

The build uses industrial-grade sensors for wide-view line detection and IR sensors for obstacle detection, combining electronics, control logic, and mechanical design into one working automation project.
